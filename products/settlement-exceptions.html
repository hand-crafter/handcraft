Shopify Settlement Exceptions

Compare Shopify payout and order exports and list amounts that need investigation.

On sale soon (download)

Checkout opens soon. Questions: handoverdesk@proton.me.

Who it is for

Shopify Payments shop owners and bookkeepers who can run Python on their own machine.

Price

  • US$19 once: proposed price for the versioned download, not a subscription

What you receive

  • A download that runs on your machine
  • A CSV and an HTML list of differences between payout transactions and orders, each with its input row number: missing charges, late pending payouts, amount differences, fee/net differences, and unmatched refunds or disputes
  • A source ledger showing which public Shopify documentation page each expected column comes from

What it does not do

  • It does not connect to Shopify, compare bank statements or accounting ledgers, or post entries
  • It does not handle multiple currencies; files with mixed payment methods stop with a plain message instead of a report
  • The expected columns come from Shopify's public documentation; they have not been confirmed against a real shop's export
  • It assumes an order total is on the first line of each order

What it has been run on

Only run on made-up exports and on an example built from the columns in Shopify's public documentation. No real shop's export has been run. Eighteen tests passed in the source folder and from a clean copy of the release.

How you receive it

Version 1.0.1 is packaged as shopify-settlement-1.0.1.zip. You run it locally with Python 3.10 or later; only Python 3.14 was tested. No work by Handcraft is needed per order. Checkout opens soon.

What leaves your machine

Payout and order exports are processed locally; you do not need to send them to Handcraft.
