Shopify Settlement Exceptions

Compare Shopify payout and order exports and list amounts that need investigation.

On sale soon (download)

Checkout opens soon. Questions: handoverdesk@proton.me.

Who it is for

Bookkeeping firms with Shopify clients.

Price

  • US$79: proposed pilot price, one closed month and one store

What you receive

  • A download that runs on your machine
  • An exception report for payout-versus-order checks, including missing or overdue payouts, fee/net mismatches, rounding, differing amounts, unmatched refunds and disputes without an original order

What it does not do

  • It does not compare bank statements or accounting ledgers
  • It does not handle multiple currencies
  • Real export columns, type values, date formats and sign conventions are unconfirmed
  • It assumes an order total is on the first line of each order

What it has been run on

Only run on made-up exports with planted exceptions. No real shop export was available. Eleven tests passed in the source folder and from a clean copy of the release.

How you receive it

Version 1.0.0 is packaged as shopify-settlement-1.0.0.zip. You run it locally with Python 3.10 or later; only Python 3.14 was tested. No work by Handcraft is needed per order. Checkout opens soon.

What leaves your machine

Payout and order exports are processed locally; you do not need to send them to Handcraft.
