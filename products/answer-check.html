Who it is for

Small online shops that pay for a support chatbot and never check what it tells shoppers.

What you receive

  • A local command that reads question-and-answer pairs in CSV or JSON and policy files
  • report.md, report.html and facts.json
  • Rules-only checks, or model checks using your own model key or judge command; rules-only mode lists skipped checks and gives no score

What it does not do

  • It does not guarantee that every wrong answer is found

  • Export support in your chatbot product has not been verified
  • The buyer-key model route has only been tested against a local stand-in server

What it has been run on

Run on Homebrew’s public Support-Tiers and Installation documentation, with 30 hand-written answer pairs: 15 correct and 15 planted errors. Rules-only mode caught 5 of 15 planted errors. Model mode, available with the buyer’s own model key, caught 15 of 15; the recorded run used the existing judge command, while the buyer-key API route was tested only with a local stand-in server. Both modes flagged 0 of 15 correct answers. This is one wiring check, not a real shop export or an accuracy guarantee. The documentation licence line remains unverified. The release passed 53 tests.

How you receive it

Version 1.0.0 is packaged as chatbot-answer-check-1.0.0.tar.gz and runs on your machine. Nothing is run by Handcraft per order. Checkout opens soon.

What leaves your machine

Rules-only mode processes local files. Model mode sends answer pairs and policy text to the model service you choose using your key or judge command. Remove shopper details first; model-service charges are yours.
