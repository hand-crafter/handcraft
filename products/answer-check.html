Chatbot Answer Check

Check exported chatbot answers against supplied policy pages and receive flagged answers with draft fixes.

Checkout opens soon. Questions: handoverdesk@proton.me.

Who it is for

Small online shops that pay for a support chatbot and never check what it tells shoppers.

Price

  • US$79: one-off test price for the download; price confirmation is still pending

What you receive

  • A local command that reads question-and-answer pairs in CSV or JSON and policy files
  • report.md, report.html and facts.json
  • Rules-only checks, or model checks using your own model key or judge command; rules-only mode lists skipped checks and gives no score

What it does not do

  • It does not guarantee that every wrong answer is found
  • It does not change your chatbot or measure lost sales
  • Export support in your chatbot product has not been verified
  • The buyer-key model route has only been tested against a local stand-in server

What it has been run on

Run on two pages of the Kubernetes documentation (Version Skew Policy and Patch Releases, CC BY 4.0) used as the policy, with 30 answer pairs written by the AI agents that built the tool: 15 correct and 15 with one planted error. Rules-only mode caught 2 of 15 planted errors, so on its own it is weak. Model mode caught 15 of 15 in one run through a judge command; the route that uses your own model key has only been tested against a local stand-in server. Both modes flagged 0 of 15 correct answers. This is a wiring check on a sample the authors wrote, not a real shop export or an accuracy guarantee. No connection to the Kubernetes project is claimed. The release passed 56 tests from a clean copy.

How you receive it

Version 1.0.2 is packaged as chatbot-answer-check-1.0.2.tar.gz and runs on your machine. Nothing is run by Handcraft per order. Checkout opens soon.

What leaves your machine

Rules-only mode processes local files. Model mode sends answer pairs and policy text to the model service you choose using your key or judge command. Remove shopper details first; model-service charges are yours.
