Agency Overflow Desk

Check saved website pages for faults and receive a fix list grouped by effort.

By request, not on sale yet

Checkout opens soon. Questions: handoverdesk@proton.me.

Who it is for

Small web agencies (two to ten people) handing client sites over.

Price

  • US$49: proposed pilot, one site, one-off
  • US$99 a month: proposed four-site offer, each checked once a month

What you receive

  • report.html and report-print.html
  • fixlist.md grouped into quick, medium and larger effort, plus facts.json
  • A list of checks the report did not cover

What it does not do

  • It does not fix the site
  • A saved folder cannot prove that live forms or booking steps work
  • Booking-step checks depend on a marker that real sites may not have
  • No WordPress run has been completed

What it has been run on

Run on Handcraft’s own storefront as a saved folder: 16 pages, 20 faults. No forms or booking steps were present. The permitted live sample address returned HTTP 404, so there was no successful live run. The release passed 61 tests.

How you receive it

By request, not on sale yet. A buyer-run version 0.2.0 archive also exists, with no routine work by Handcraft per run; it is not offered for checkout here. A by-request delivery process and time estimate are not established in the note.

What leaves your machine

Folder mode reads saved pages on the machine running the check. Address mode fetches public pages. A Handcraft-run request would require sharing the saved public pages; no input collection is enabled here.
