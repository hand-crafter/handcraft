Fivetran Bill Audit

Check Fivetran billing exports against Snowflake read records and compare cost scenarios using rates you supply.

Checkout opens soon. Questions: handoverdesk@proton.me.

Who it is for

Teams that pay Fivetran to load data into Snowflake and want to understand their bill.

Price

  • Free: the preflight (history coverage, top tables and connections by paid rows), public code
  • US$149: the full report, one-off

What you receive

  • A local download with preflight and full-report commands
  • Reports of candidate tables, spikes and pricing scenarios, with confidence levels and estimate limits
  • Plain messages naming the file and fix when required input is missing or invalid

What it does not do

  • It does not establish that a table is safe to remove or promise savings
  • Pricing scenarios are alternatives, not amounts to add together; they are not vendor advice
  • The SQL has never run on a warehouse
  • Mixed-account detection uses connection ids and names; identical names across accounts can escape detection
  • Mixed-currency and mixed-destination checks beyond that are not built

What it has been run on

Only run on made-up exports. The 44 automated tests pass from the release archive; the SQL has been parsed offline but has never run on a real warehouse.

How you receive it

Version 1.0.0 is packaged as handcraft-bill-audit-1.0.0.zip. You run the download on your machine; no work by Handcraft is needed per order. Checkout opens soon.

What leaves your machine

Nothing leaves your machine. The tool makes no network calls.
