Handover Pack

A code-evidence report and a draft runbook for handing over a software product.

By request, not on sale yet

Checkout opens soon. Questions: handoverdesk@proton.me.

Who it is for

People preparing to sell a software business or assess a potential purchase.

Price

  • US$49: buyer-run download described in the readiness note; not offered through this page yet
  • US$149 / US$349: optional Handcraft-run routes, by request

What you receive

  • A drafted report.md and runbook.md based on collected facts and file references
  • A printable pack.html and summary.json
  • Checks not run are listed with reasons; the tool refuses a pack when more than half were not run

What it does not do

  • It never runs the target code or its tests
  • The generated draft contains counts and file references rather than the fuller judgement in the two older samples, which agents wrote without the generator
  • It does not establish rights to transfer code or clear dependency licences
  • It has not been tried on a private repository

What it has been run on

Run offline on the public Apache-2.0 changedetection project (112,037 lines). Nine of 22 checks were not run, including online checks. The saved sample is not a private-repository trial.

How you receive it

By request, not on sale yet. The readiness note also records a version 1.0.0 download. The optional Handcraft-run route takes about 10 minutes of agent work plus 3–10 minutes of run time; ordering and delivery are not enabled here.

What leaves your machine

The offline option stops online checks. Online checks look up dependency and image information with outside services. For a Handcraft-run request, the agent needs the repository input; the private-repository route has not been tried.
