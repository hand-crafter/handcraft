Handover Pack

A code-health report and a draft handover runbook that you generate on your own copy of the code.

On sale soon (download)

Checkout opens soon. Questions: handoverdesk@proton.me.

Who it is for

People preparing to sell a software business or assess a potential purchase.

Price

  • US$49 once: the versioned download you run yourself, not a subscription
  • The scanners it can call are free, open-source tools, and GitHub already gives every repository dependency alerts at no charge. The price is for one report a buyer can read, a licence-text check and a draft handover runbook, produced without the code leaving your machine

What you receive

  • A download that runs on your macOS or Linux machine with one command against your local Git checkout
  • report.md, runbook.md, a printable pack.html, summary.json and facts.json written to a folder beside the checkout
  • Every check is labelled checked and found, checked and nothing found, or not checked, with its scope and reason

What it does not do

  • It never runs the target code, its tests or its install scripts
  • It is always offline, so vulnerability, package and container-image lookups are not checked
  • A missing optional scanner means a missing section, not a clean result
  • The handover steps are proposals to confirm, not instructions proved to work
  • It does not establish rights to transfer code, clear dependency licences, certify security or value the business
  • It has not been tried on a private repository or on a Linux machine

What it has been run on

Run from the release archive on a read-only copy of the public MIT-licensed Linkding project: 395 files read, 6 checks ran, 6 ran partly and 10 did not run. Twenty automated tests pass from a clean copy of the release. No private repository and no Linux machine has been tested.

How you receive it

Version 1.1.0 is packaged as handover-pack-1.1.0.tar.gz. You run it locally; it needs Bash, Git and Python 3.11 or later. No work by Handcraft is needed per order. Full refund within 7 days if the tool cannot read your repository. Checkout opens soon.

What leaves your machine

Nothing leaves your machine. The download makes no network calls and you do not send code to Handcraft.
